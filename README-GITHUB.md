## 📱 O que é o ROTA PRIME?

**ROTA PRIME** é um aplicativo **Android** para quem faz **rotas de entrega** com romaneio (planilha), paradas manuais ou mistura dos dois. Tudo no **mapa**, com **GPS**, progresso de pacotes e registro **Entregue / Não entregue**.

| | |
|---|---|
| 📄 **Importação** | Planilha **XLSX** (romaneio) ou rota **100% manual** |
| 🗺️ **Mapa** | Pins numerados, sua posição, lista de paradas e modo **Mapa · Lista** |
| 🚚 **Entrega** | Abrir GPS (Waze/Google), marcar status, vários pacotes no **mesmo endereço** |
| 💾 **Dados** | Rotas salvas **no celular**; retoma rota ativa ao reabrir o app |
| 🔒 **Privacidade** | Sem conta obrigatória; licença PRO amarrada ao **ID do aparelho** |

**Versão atual:** `1.0.1` · Android (APK universal: arm64, arm32, x86_64)

## 📥 Instalação

1. Abra **[Releases](https://github.com/ALN2025/rotaprime/releases/latest)** e baixe **`ROTA_PRIME.apk`**.

3. Toque no arquivo baixado e conclua a instalação.

## 🔑 PRO — chave de ativação (destaque)

> **No app: abra `Mais` → `Configurações`.**  
> Lá você encontra o **ID do aparelho** (copie) e, mais abaixo, o botão verde **「Suporte」** (WhatsApp).

**Para pedir a chave PRO:** toque em **Suporte**, envie uma mensagem pedindo a **chave de ativação** e **informe o ID do aparelho** que você copiou na mesma tela.

**Depois de receber a chave:** em **Configurações → Assinatura**, toque na licença e **cole a chave** recebida (válida só para aquele ID).

| Passo | Ação |
|:-----:|------|
| 1️⃣ | **Configurações** → copiar **ID do aparelho** |
| 2️⃣ | **Suporte** (WhatsApp) → pedir chave PRO + **enviar o ID** |
| 3️⃣ | **Assinatura** → colar a licença |

## 🧭 Como usar (resumo)

1. **📂 Importar** planilha ou **➕ criar** paradas manualmente.  
2. **👀 Revisar** paradas no mapa; corrija endereço pelo menu **⋮ → Editar endereço** se precisar.  
3. **▶️ Iniciar rota** e ir entregando.  
4. **✅ Entregue** ou **❌ Não entregue** em cada parada.  
5. **🏁 Terminei as entregas** quando concluir o dia.

No **PRO**, antes de iniciar: **Otimizar rota** para ordem inteligente e **linha laranja** pelas ruas.

## 🆓 Planos Grátis e ⭐ PRO

### 🆓 Grátis — ordem da planilha, mapa limpo

Ideal para seguir a **sequência do romaneio** (1 → 2 → 3…).

| Recurso | |
|--------:|---|
| 📊 Importar planilha XLSX | ✅ |
| 🗺️ Mapa, pins e GPS | ✅ |
| 📋 Ordem igual à planilha / manual | ✅ |
| ✏️ Parada manual (rua, nº, bairro, cidade) | ✅ |
| 📍 Editar endereço do pin | ✅ |
| ✅❌ Entregue / Não entregue | ✅ |
| 📦 Vários pacotes no mesmo endereço | ✅ |
| 🟧 Linha laranja no mapa (rota pelas ruas) | ❌ |
| 🧠 Otimização OSRM (menor caminho) | ❌ |
| ⏱️ Tempo / distância estimados (OSRM) | ❌ |
| 🔄 Reotimizar após mudanças | ❌ |
| 📮 Cadastro por CEP + número | ❌ |
| 💰 Controle de gastos e lucro | ❌ |

No **Grátis**, ao **Iniciar rota** você vê **pins + GPS**, **sem** traçado laranja de navegação. Toque no pin para focar a entrega; a ordem segue a **planilha**.

---

### ⭐ PRO — rota inteligente e trecho até o alvo

Tudo do Grátis, **mais**:

| Recurso | |
|--------:|---|
| 🧠 **Otimização de rota (OSRM)** | Ordem sugerida para caminho mais eficiente |
| 🟧 **Linha laranja** | Rota completa e **trecho GPS → pin** pelas ruas |
| 📍 **Pin alvo** | Toque em outro pin: recalcula o trecho (com rota **otimizada**) |
| 🎯 **Parada mais próxima** | Modo automático prioriza proximidade (após otimizar) |
| ⏱️ **Tempo e distância** estimados | Após otimizar |
| 🔄 **Reotimizar** | Menu ☰ → *Reotimizar rota* (após alterar paradas) |
| 📡 **Otimizar a partir do GPS** | Partida na sua posição atual |
| 📮 **CEP + número (ViaCEP)** | Cadastro rápido |
| 💰 **Controle de gastos** | KM, despesas, valor da rota, lucro |

> **Importante (PRO):** a linha laranja e o trecho até o pin exigem **Otimizar rota** antes de **Iniciar**. Depois de mudar endereços, use **Reotimizar**.
